# Asset Manifest — Shadows of Transoxiana

_Last updated: 2026-10-14._

## 0. Rules

- **Status values:** `Procedural (in code)` · `Available` (free, identified, not yet
  imported) · `Missing` (no suitable free source found) · `Placeholder` (works, must be
  replaced) · `Imported` (in the project) · `Deferred` (later milestone).
- **Never** use random web images as textures or as substitutes for 3D models. Museum
  links in `VISUAL_DIRECTION.md` are for study only.
- **No purchases or subscriptions** without the project owner's explicit approval.
- **Public repo warning:** Epic/Fab, Mixamo, Sonniss and Pixabay *source files* must not
  be pushed to a **public** repository. Either keep this GitHub repo **private** (the Fab
  licence allows sharing with collaborators via a private repository) or keep those
  folders out of Git. CC0 / CC-BY / OFL files may be committed (CC-BY needs an entry in
  `CREDITS.md`).
- Licence information was gathered from search results on 2026-10-14; the research
  machine could not open the pages. **Re-read the licence on the page before
  importing** and record the date you checked in the table.
- Destination folders are under `Content/` (shown in the editor as `/Game/`).

### Licence quick reference
| Licence | Commercial | Attribution | Public repo |
|---|---|---|---|
| Unreal Engine EULA / Epic Content License / Fab Standard License | Yes (in UE projects) | No | **No** — private only |
| Mixamo (Adobe) | Yes, royalty-free | No | **No** raw FBX redistribution |
| CC0 (Poly Haven, ambientCG, Kenney, Quaternius) | Yes | No | Yes |
| CC-BY 4.0 (some Sketchfab, Freesound) | Yes | **Yes** — record in `CREDITS.md` | Yes |
| CC-BY-NC / BBC RemArc | **No** | Yes | — **do not use** |
| SIL OFL (Google Fonts) | Yes | No (include `OFL.txt`) | Yes |
